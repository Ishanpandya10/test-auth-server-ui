SMVS BFF Flow Tester

Tests the full browser flow: POST /app/session (exchange legacy auth_token → JWT, set SESSION cookie), then secured pings to account-management and spk-management through the gateway. Every call uses credentials: "include", so this exercises the real CORS + cookie path. Serve this file over the same scheme you use for the gateway (HTTPS in UAT/PROD; the SESSION cookie is Secure and will be dropped over plain HTTP).
